# Water–Methanol Flash Separation

## Project Description
This Python project studies the flash separation of a water–methanol mixture using the Rachford–Rice equation and vapor–liquid equilibrium principles.

## Features
- Calculation of the vapor fraction using the Rachford–Rice equation.
- Determination of liquid and vapor flow rates and compositions.
- Verification of component mass balances.
- Plotting of the T-x-y equilibrium diagram.
- Comparison with reference results obtained using DWSIM.

## Technologies
- Python
- NumPy
- SciPy
- Matplotlib
- DWSIM (reference simulation)

## Objective
To apply numerical methods and thermodynamic concepts to chemical engineering separation processes.

## Note
The flash calculation and the T-x-y diagram use different equilibrium assumptions in this version. The diagram uses Raoult’s law, while the reference DWSIM results may use a different thermodynamic model.
